Application API

These endpoints use your account session. Changes require an X-CSRFToken header. Fetch /api/v1/csrf first; sign-in rotates the token.

Try a request

While signed in, use this in your site's browser console:

const { api } = await import('/static/js/api-client.js');
const result = await api('/api/v1/resources');
console.log(result.data);

List parameters: q, sort, page, and per_page (1–50). Decimal fields use decimal strings for precision. Validation errors return 422; stale versions return 409. The included API guide contains sign-in, CRUD, and file examples.
