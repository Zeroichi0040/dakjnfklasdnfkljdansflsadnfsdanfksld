FLASK FULLSTACK FRAMEWORK · 3.0

Your application.
A reusable foundation.

A Flask backend, SQL database, rendered frontend, browser API client, account system, and resource engine. Add a feature by defining its data and rules; the framework connects its forms, pages, API, permissions, and documentation.

Start the application ↓
This is the opening guide. The application runs through Python. Extract the ZIP into a new folder, then start its server using the steps below. Do not open individual frontend templates as a website.

Open it in three steps

Windows

1

Have Python 3.12 or 3.13 installed.

If Python Install Manager reports a missing runtime, run:

py install 3.13

Or install Python from python.org.

2

Double-click SETUP_WINDOWS.bat.

Wait for SETUP COMPLETE. First setup needs internet. In PowerShell:

.\SETUP_WINDOWS.bat

Direct alternative with your installed version:

py -3.12 scripts\bootstrap.py
3

Double-click START_WEBSITE.bat.

.\START_WEBSITE.bat

Open http://127.0.0.1:5000 and create your account.

macOS / Linux

1

Install Python 3.12 or 3.13.

Supported range: 3.11–3.14. Open a terminal in the extracted folder.

2

Install and prepare the database.

bash setup.sh

Setup creates a private environment, unique settings, and a migrated SQL database.

3

Start the application.

bash start.sh

Open http://127.0.0.1:5000. Keep the terminal open; Ctrl+C stops the server.

Build a new feature

Use your project's Python, or activate .venv first:

python manage.py make-resource products --field name:text --field price:decimal --field stock:integer
python manage.py db migrate -m "Add products"
# Review the new migration, then:
python manage.py db upgrade

Restart. Visit /app/products for its frontend and /api/v1/products for its API. Forms, list/detail/edit/delete pages, validation, policies, pagination, export, navigation, and OpenAPI are connected by the resource engine.

Try the working full request cycle

  1. Sign up and add a private note through its form.
  2. Use Refresh on its list: the browser reads the real JSON API.
  3. Restart the app and confirm the record remains in SQL.
  4. Sign in as another account and confirm it cannot read that record.
  5. Create an administrator, publish a Website page, and visit its public URL while signed out.

Create an administrator

# Windows
.venv\Scripts\python.exe manage.py create-admin
# macOS / Linux
.venv/bin/python manage.py create-admin

The command prompts for your own credentials. No shared account is installed.
