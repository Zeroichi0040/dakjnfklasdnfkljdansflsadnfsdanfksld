# Local illustration attribution

All SVGs in `frontend/static/images/bakery/` were drawn specifically for this
reference application during implementation. They use vector shapes and gradients,
contain no third-party photos, fonts, embedded scripts or external URLs, and need
no external image service. Credit: Mithi Bakehouse reference implementation, 2026.
They may be studied and modified with the application, subject to the repository's
applicable licensing; no separate third-party image licence is introduced.

`bread.svg`, `pastry.svg`, `cake.svg`, `cookie.svg`, `bun.svg` are category illustrations,
shared by sample products. `hero.svg` is an original illustrated bakery basket.
They are explicitly illustrations, not photographs of real products. Sample names,
allergens, descriptions and prices are educational data, not a real bakery offer.
System fonts are used; no remote font download is required.
